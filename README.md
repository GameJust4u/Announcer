# lolka-announcer

Страничка-отправлялка в Discord через вебхуки: кнопки событий, свои сообщения,
отложенная отправка по расписанию, гостевой режим и антиспам.

## Файлы
- `send.html` — страничка (кнопки, сообщение, расписание, вход)
- `server.py` — сервер (вебхуки, авторизация, планировщик, антиспам)
- `manifest.webmanifest`, `icon-192.png`, `icon-512.png` — иконки PWA
- `Procfile`, `requirements.txt` — для Railway

## Переменные окружения на Railway

| Переменная | Что это |
|---|---|
| `DISCORD_WEBHOOK_1` | вебхук канала для «Раскопок» |
| `DISCORD_WEBHOOK_2` | вебхук канала для остальных кнопок и своих сообщений |
| `PAGE_PASSWORD` | пароль входа. Если пусто — авторизация выключена |
| `BOT_NAME` | имя, от которого летят сообщения (по умолчанию BL9D BOT) |
| `SESSION_SECRET` | любая случайная строка, чтобы вход переживал перезапуски |

## Режимы
- **Гость (без пароля):** доступна только кнопка «Раскопки» (в том числе отложенная). Остальное заблокировано и на страничке, и на сервере.
- **После входа:** все кнопки, свои сообщения с выбором канала и расписание.

## Антиспам
- После любой отправки одной и той же кнопки/текста — пауза 15 секунд для ВСЕХ пользователей (константа `COOLDOWN` в `server.py`).
- На каждый текст может висеть только один отложенный таймер; повтор — ошибка «уже запланировано».

## Важно
Таймеры живут в памяти: при перезапуске Railway запланированные сообщения пропадут.
Если нужна надёжность — попросите добавить сохранение расписания в SQLite.

## Деплой
1. Положите все файлы в одну папку и залейте на GitHub.
2. Railway → New Project → Deploy from GitHub repo.
3. Задайте переменные из таблицы выше (можно сгенерировать SECRET командой `python -c "import secrets; print(secrets.token_hex(16))"`).
4. Generate Domain — пользуйтесь. На телефоне: «Добавить на главный экран».
