# BL9D LOLKA ANNOUNCER 💬

Страничка с кнопками, которая отправляет сообщения в Discord через вебхуки.
Кнопка «Раскопки» пишет в один канал, остальные — во второй. Есть отложенная
отправка по дате и времени и вход по паролю (кука на год, пароль вводится
один раз на устройстве).

## Файлы

- `send.html` — страничка (кнопки, своё сообщение, выбор канала, расписание)
- `server.py` — сервер: хранит вебхуки, авторизация, планировщик
- `Procfile` — команда запуска для Railway
- `requirements.txt` — заглушка, внешних зависимостей нет
- `manifest.webmanifest`, `icon-192.png`, `icon-512.png` — PWA для установки на главный экран

## Переменные окружения (Railway -> Variables)

| Переменная | Что это |
|---|---|
| `DISCORD_WEBHOOK_1` | вебхук канала для «Раскопок» |
| `DISCORD_WEBHOOK_2` | вебхук канала для «Засада/Осада/Пандоры» и своих сообщений по умолчанию |
| `PAGE_PASSWORD` | пароль для входа на страничку (пусто = авторизация выключена) |
| `BOT_NAME` | имя, от которого приходят сообщения (по умолчанию `BL9D BOT`) |
| `SESSION_SECRET` | случайная строка — чтобы вход переживал перезапуски Railway |

## Локальный запуск

```bash
set DISCORD_WEBHOOK_1=...        # Windows (Linux/macOS: export ...)
set DISCORD_WEBHOOK_2=...
set PAGE_PASSWORD=...
set SESSION_SECRET=...
python server.py
```

Открыть http://localhost:8080

## Railway

1. Залейте файлы в GitHub-репозиторий (секретов в коде нет — пушить безопасно).
2. railway.com -> New Project -> Deploy from GitHub repo.
3. Variables: добавьте переменные из таблицы выше.
4. Networking -> Generate Domain — получите публичную ссылку.

## Перевесить кнопку на другой канал

В `server.py` есть словарь `BUTTON_WEBHOOKS`: поменять значение `1`/`2`
у нужной кнопки — и она будет писать в другой канал.

## Важно

- Расписание живёт в памяти сервера: при перезапуске Railway запланированные
  сообщения сбрасываются.
- Не передавайте ссылку и пароль тем, кому не доверяете: любой вошедший может
  писать в ваши каналы от имени бота.
