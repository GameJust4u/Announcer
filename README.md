# BL9D LOLKA ANNOUNCER

Страничка с кнопками, которая отправляет сообщения в Discord через вебхуки.
Пароль вводится один раз на устройстве (кука на год). Есть отложенная отправка.

## Два канала

- Кнопка **Раскопки** -> вебхук 1 (`DISCORD_WEBHOOK_1`)
- Кнопки **Засада, Осада, Пандора А, Пандора Б** -> вебхук 2 (`DISCORD_WEBHOOK_2`)
- Своё сообщение -> канал на выбор (переключатель под полем ввода)

## Отложенная отправка

Выбери дату и время в поле «Отправить по расписанию» — следующий клик по любой
кнопке (или «Отправить») запланирует сообщение. Оно уйдёт само, когда время
наступит. Важно: расписание живёт в памяти сервера, после перезапуска Railway
запланированные сообщения пропадают.

## Переменные окружения (Railway -> Variables)

| Переменная | Значение |
|---|---|
| `DISCORD_WEBHOOK_1` | вебхук канала для «Раскопки» |
| `DISCORD_WEBHOOK_2` | вебхук канала для остальных кнопок |
| `BOT_NAME` | `BL9D BOT` |
| `PAGE_PASSWORD` | пароль для входа на страничку |
| `SESSION_SECRET` | любая случайная строка (чтобы вход переживал перезапуски) |

## Деплой на Railway

1. Залей файлы в GitHub-репозиторий (секретов в коде нет — пушить безопасно).
2. railway.com -> New Project -> Deploy from GitHub repo.
3. Вкладка Variables: добавь переменные из таблицы выше.
4. Вкладка Networking -> Generate Domain -> открывай ссылку.
5. Войди один раз паролем — дальше кнопки доступны без ввода.

Локальный запуск: `python server.py` -> http://localhost:8080
(переменные окружения задать перед запуском).
